# Engineering standards

## Naming (Azure)

Pattern `<type>-<workload>-<env>-<region>-<nn>`, generated by `infra/terraform/modules/naming` — never hand-written.

| Resource | Example |
|---|---|
| Resource group | `rg-plat-prod-cac-01` |
| AKS | `aks-plat-prod-cac-01` |
| Key Vault (≤ 24) | `kv-hbl-plat-prod-cac01` |
| Container registry | `acrhblmgmtsharedcac01` |
| PostgreSQL | `psql-ins-prod-cac-01` |
| Service Bus | `sbns-ins-prod-cac-01` |
| Managed identity (workload) | `id-ins-policy-api-prod` |

Region codes: `cac` Canada Central, `cae` Canada East. Environments: `dev`, `stg`, `prod`, `shared`.

## Tagging (mandatory, enforced by Azure Policy on resource groups)

| Tag | Example | Purpose |
|---|---|---|
| `environment` | `prod` | Policy scope, cost |
| `owner` | `insurance-digital` | Accountability (Backstage group) |
| `cost-center` | `CC-2040` | Chargeback |
| `data-classification` | `restricted` | Data handling controls |
| `criticality` | `tier-1` | SLOs, DR priority |
| `managed-by` | `terraform` | Drift ownership |
| `repository` | `harborline/harborline-idp` | Source of truth |

## Kubernetes

- Labels: `app.kubernetes.io/{name,instance,version,part-of,component,managed-by}`, `harborline.io/{team,system,tier,data-classification,environment}`.
- Namespaces: one per team (`<team>`); platform namespaces are reserved (`argocd`, `kyverno`, `observability`, `backstage`).
- Images: `acrhblmgmtsharedcac01.azurecr.io/<team>/<app>@sha256:…`.

## Code

| Language | Standard |
|---|---|
| Python | 3.12, ruff (lint + format), mypy strict for new modules, pytest, structured logging |
| TypeScript | strict mode, ESLint via Backstage CLI / tsc, vitest |
| Terraform | `terraform fmt`, tflint (azurerm ruleset), documented variables/outputs, no hard-coded names |
| YAML | yamllint (`.yamllint.yaml`), 2-space indent |
| Shell | `set -euo pipefail`, ShellCheck clean |
| Commits | Conventional Commits; `AI-Assisted:` trailer when applicable |

## APIs

- REST, JSON, versioned path (`/api/v1`), RFC 9457 problem details, OpenAPI checked in and registered in Backstage.
- Events: CloudEvents 1.0, `com.harborline.<aggregate>.<event>` types, no PII in payloads.

## Logging retention

Interactive 90 days; audit-relevant tables (AKS audit, firewall, activity) 2 years total retention in Log Analytics.
