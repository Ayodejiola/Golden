# Platform product charter

## Mission

Make the secure, reliable way the **fastest** way to ship software at Harborline.

## Customers

Product engineering teams (primary), SRE and Security (partners), engineering leadership (sponsors). See
[personas and journeys](personas-and-journeys.md).

## Value proposition

| For engineers | For the organisation |
|---|---|
| New service to production-ready dev environment in < 1 day | Consistent controls mapped to NIST CSF, CIS, ASVS |
| No tickets for namespaces, pipelines, identities, dashboards | Audit evidence generated by default |
| One place to find owners, docs, APIs, runbooks | Lower cost per service through shared runtime |
| AI assistance grounded in our platform | Faster, safer change (DORA) |

## Scope

**In:** landing zone application layer, AKS runtime, GitOps, CI/CD templates, golden-service chart, policies,
observability, developer portal, templates, AI guardrails, reference app.
**Out:** ALZ core (enterprise cloud team), end-user computing, data platform (separate product), business applications.

## Operating model

- Platform-as-a-product: roadmap, user research, NPS, release notes, deprecation policy (2 releases notice).
- Team topology: platform team (enabling + platform), stream-aligned product teams as customers; Security and SRE as
  enabling teams. X-as-a-Service interactions by default; collaboration mode for new capabilities.
- Contract: `golden-service` values schema, template parameters and Terraform module interfaces follow SemVer.

## Success measures

See [metrics](metrics.md): adoption, time-to-first-deploy, DORA, developer satisfaction, control coverage.
